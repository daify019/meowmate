# 桌面猫咪伙伴交互与系统设计

## 1. 核心交互逻辑

桌面猫咪的交互由三层组成：

- 输入层：鼠标点击、拖动、右键菜单、鼠标靠近。
- 状态层：根据输入、时间和成长数据切换动作。
- 表现层：将状态渲染为动画、位移、表情和轻提示。

默认节奏：

1. 猫咪空闲 3 到 8 秒。
2. 行为调度器根据品种权重和当前状态选出下一动作。
3. 动作持续一段时间后回到 idle。
4. 用户互动会打断当前动作，但睡觉和不高兴有短暂保护时间。

## 2. 动作状态

| 状态 | 触发来源 | 表现 | 数据影响 |
| --- | --- | --- | --- |
| idle | 默认状态 | 眨眼、尾巴轻摆 | 能量缓慢恢复 |
| walk | 自动调度 | 沿屏幕边缘小步走 | 能量下降 |
| sleep | 能量低或布偶高权重 | 趴下、呼吸起伏 | 能量恢复 |
| clicked | 用户点击 | 抬头、爱心或惊讶 | 亲密度增加 |
| dragged | 用户拖动 | 身体拉伸、表情变化 | 轻微降低心情 |
| happy | 互动成功 | 眯眼、蹭蹭 | 心情增加 |
| annoyed | 频繁打扰 | 背过身、皱眉 | 心情降低 |
| special | 品种特殊动作 | 每个品种独有 | 增加经验 |

当前实现已经放弃程序化自绘，改为图片帧动画资源驱动。`CatWidget` 从 `assets/cats/tiny_kitten_cc0` 读取透明 PNG 帧，并根据不同猫咪品种做运行时调色。动作切换由 `BehaviorState.previous_action` 与 `transition_frame` 驱动，使用缓动和淡入混合，避免从静止、行走、睡觉、开心等状态之间生硬跳变。

视觉预览见 `docs/sprite_cat_preview.png`。

## 3. 品种与性格系统

每个品种由 `CatBreed` 定义：

- `id`：稳定唯一标识。
- `display_name`：展示名称。
- `appearance`：颜色、纹理、眼睛、尾巴等绘制参数。
- `personality`：性格文本。
- `behavior_weights`：动作权重。
- `special_action`：特殊动作名称。
- `interaction_bias`：对点击、拖动、鼠标靠近的偏好。

示例：

- 暹罗猫：`talkative` 高，`follow_mouse` 高，special 为 meow。
- 布偶猫：`sleep` 高，`happy` 高，移动速度低。
- 玳瑁猫：随机性高，`annoyed` 触发阈值更低。

## 4. 成长系统

成长数据由 `CatStats` 保存：

- `energy`：0 到 100。
- `mood`：0 到 100。
- `affection`：0 到 100。
- `xp`：累计经验。
- `level`：由 xp 计算，`level = 1 + xp // 100`。
- `last_interaction_at`：用于判断冷却和频繁点击。

成长规则：

- 点击：亲密度 +1，经验 +1。
- 逗猫：心情 +3，能量 -2，经验 +2。
- 喂食：能量 +8，心情 +2。
- 睡觉：每轮能量 +2。
- 频繁点击：心情 -4，并可能触发 annoyed。

## 5. 桌面行为

窗口默认放在主屏幕右下角附近，猫咪不会主动离开屏幕可见区域。

移动策略：

- walk 状态沿水平轴移动。
- 到达屏幕边缘后翻转朝向。
- 狸花猫特殊动作可短距离跳向鼠标。
- 暹罗猫在高亲密度时更容易靠近鼠标。

低打扰策略：

- 不展示强弹窗。
- 不播放默认声音。
- 动画帧率限制在约 12 FPS。
- 用户正在拖动时停止自动位移。

## 6. UI 设计

### 6.1 新手引导

布局：

- 左侧：猫咪预览。
- 右侧：品种列表、性格说明、开始按钮。

关键文案：

- 标题：选择你的桌面猫咪伙伴。
- 按钮：带它回桌面。

### 6.2 右键菜单

菜单项：

- 逗逗它。
- 喂小鱼干。
- 让它睡一会儿。
- 特殊动作。
- 设置。
- 退出。

### 6.3 设置面板

设置分组：

- 猫咪：品种选择、当前性格。
- 行为：互动强度、移动速度、静音。
- 显示：缩放、始终置顶。
- 数据：心情、能量、亲密度、等级、重置数据。

## 7. 代码扩展点

新增猫咪：

1. 在 `cat_catalog.py` 新增 `CatBreed`。
2. 配置外观颜色和行为权重。
3. 如需新特殊动作，在 `CatAction` 增加枚举。
4. 在渲染层添加对应表现。

新增资源动画：

1. 定义资源目录：`assets/cats/<breed>/<action>/frame_001.png`。
2. 新增 `SpriteRenderer`。
3. 保持状态机不变，只替换表现层。

新增互动：

1. 在右键菜单或鼠标事件中添加入口。
2. 在 `BehaviorEngine` 中改变状态和成长数据。
3. 在设置面板中展示必要开关。
