# 桌面猫咪伙伴产品需求文档

## 1. 产品概述

产品名称建议：Desktop Cat Pal / 桌面猫咪伙伴 / MeowMate。

一句话描述：一款可以在桌面上陪伴用户的猫咪宠物程序，用户可以选择不同品种的猫咪，让它们在桌面边缘行走、睡觉、卖萌、撒娇，并与用户进行轻量互动。

产品风格：可爱、轻量、不打扰用户、低资源占用，适合长期运行在 Windows / macOS 桌面环境。

## 2. 目标用户

- 喜欢猫但暂时无法养猫的人。
- 长时间使用电脑，需要陪伴感和情绪缓解的人。
- 喜欢桌面美化、可爱小组件、虚拟宠物的用户。
- 想要一个轻量、治愈、不打扰工作的桌面小宠物的用户。

## 3. 设计原则

- 陪伴优先：猫咪存在感温柔，不频繁弹窗，不遮挡关键工作区域。
- 可长期运行：默认低帧率、低 CPU、低内存，不依赖持续联网。
- 可爱但克制：互动反馈要有情绪，但不打断用户。
- 数据驱动：品种、性格、动作、状态权重和皮肤均可配置。
- 渐进扩展：先支持程序化动画，后续可替换为精灵图、Spine、Lottie 或 Live2D。

## 4. 核心用户旅程

1. 用户首次启动程序。
2. 程序展示猫咪选择引导。
3. 用户选择猫咪品种并命名。
4. 猫咪出现在桌面右下角或屏幕边缘。
5. 猫咪根据性格自动活动：走动、睡觉、观察鼠标、卖萌。
6. 用户点击、拖动、右键或靠近鼠标时触发互动。
7. 猫咪积累亲密度、心情和能量变化，逐渐解锁更多动作。
8. 用户可通过右键菜单进入设置，切换猫咪、调节尺寸和行为强度。

## 5. 首批猫咪品种

| 品种 | 外观特征 | 性格设定 | 行为风格 | 特殊动作 |
| --- | --- | --- | --- | --- |
| 暹罗猫 | 浅色身体，深色脸、耳朵、尾巴 | 话痨、粘人、活泼 | 经常叫，喜欢靠近鼠标 | 不停喵喵叫 |
| 美短猫 | 银灰虎斑纹 | 友好、稳定、好奇 | 经常探索屏幕边缘 | 蹲坐洗脸 |
| 布偶猫 | 长毛、蓝眼睛、柔和配色 | 温顺、慵懒、亲人 | 更爱睡觉、翻肚皮 | 躺倒翻肚皮 |
| 黑猫 | 全黑毛色，亮眼睛 | 神秘、安静、机敏 | 喜欢突然出现、蹲坐观察 | 缩成黑影或突然睁眼 |
| 狸花猫 | 棕灰虎斑、本土猫感 | 独立、聪明、活跃 | 喜欢跳跃、抓屏幕边缘 | 扑向鼠标 |
| 玳瑁猫 | 黑橘混合花纹 | 傲娇、情绪丰富 | 随机行为较多，偶尔不理人 | 扭头不理用户 |

每种猫至少包含：静止、行走、睡觉、被点击、被拖动、开心、不高兴、特殊动作。

## 6. 功能需求

### 6.1 初次启动与选择

- 首次启动展示选择面板。
- 用户可预览不同猫咪外观和性格描述。
- 用户可选择猫咪并进入桌面。
- 默认猫咪名称为品种名，也允许后续扩展昵称。

验收标准：

- 未保存设置时自动弹出新手引导。
- 选择后保存到本地，下次启动直接显示桌面猫咪。

### 6.2 桌面宠物窗口

- 无边框、透明背景、置顶显示。
- 支持拖动移动。
- 默认不抢占键盘焦点。
- 可设置尺寸缩放。
- 鼠标右键打开菜单。

验收标准：

- 猫咪窗口背景透明。
- 鼠标左键拖动可改变位置并保存。
- 右键菜单可打开设置、切换行为、退出程序。

### 6.3 自动行为

- 猫咪根据能量、心情、亲密度和品种性格自动选择动作。
- 高能量时更容易行走、跳跃、靠近鼠标。
- 低能量时更容易睡觉。
- 高亲密度时更容易开心、撒娇。
- 低心情或被频繁打扰时出现不高兴。

验收标准：

- 程序运行 1 分钟内至少出现 2 种自动动作。
- 不同品种自动行为分布明显不同。

### 6.4 用户互动

- 点击猫咪：触发点击反馈，心情和亲密度小幅增加。
- 连续频繁点击：可能触发不高兴。
- 拖动猫咪：进入拖动状态，放开后恢复。
- 鼠标靠近：粘人型猫咪可能靠近鼠标，独立型猫咪可能观察或躲开。
- 右键菜单：快速喂食、逗猫、睡觉、设置、退出。

验收标准：

- 点击、拖动和右键菜单均可响应。
- 互动会改变本地成长数据。

### 6.5 成长系统

- 能量 energy：影响行动和睡眠概率。
- 心情 mood：影响开心/不高兴反馈。
- 亲密度 affection：影响撒娇、特殊动作和靠近鼠标概率。
- 等级 level：由累计互动经验推导。
- 经验 xp：点击、喂食、逗猫和每日陪伴增加。

验收标准：

- 成长数据保存在本地。
- 设置面板可展示基础状态。

### 6.6 设置面板

- 切换猫咪品种。
- 开关始终置顶。
- 调整宠物缩放。
- 调整移动速度。
- 调整互动强度。
- 静音开关。
- 重置宠物数据。

验收标准：

- 修改设置后立即生效。
- 关闭重开后设置保持。

## 7. 非功能需求

- Windows/macOS 可运行。
- 默认 CPU 占用低，空闲状态避免高帧率刷新。
- 本地优先，不强依赖网络。
- 稳定运行，设置损坏时可自动恢复默认值。
- 所有资源和品种定义模块化，便于扩展。

## 8. 技术推荐

首选方案：Python + PySide6。

- 桌面框架：PySide6，支持透明窗口、跨平台、系统托盘、菜单和设置面板。
- 动画资源：MVP 使用 QPainter 程序化绘制；正式版可替换为 PNG 精灵图序列或 Spine/Lottie。
- 本地数据：JSON 配置文件，路径由 platformdirs 获取；后续可升级 SQLite。
- 打包方案：PyInstaller 或 Briefcase。
- 开发环境：conda 管理 Python 与 PySide6。

备选方案：

- Tauri + Python 后端：适合后续做更复杂设置 UI，但透明桌面宠物层需要更多平台适配。
- Electron：生态成熟，但资源占用偏高，不符合轻量优先。

## 9. MVP 范围

MVP 必须包含：

- 6 种猫咪。
- 透明桌面宠物窗口。
- 点击、拖动、右键菜单。
- 自动行为状态机。
- 设置面板。
- 本地保存。

MVP 暂不包含：

- 真实叫声音频。
- 云同步。
- 插件市场。
- 复杂物理碰撞。
- 多宠物同屏。
